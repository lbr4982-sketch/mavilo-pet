# daily-log — 하루 일지

`YYYY-MM-DD.md` 하나 = 하루. `night-desk`가 03:10에 그날의 **빈 표**를 만들어 두고, 사장님이 21:00에 채웁니다.
이 폴더가 `weekly-report`의 **유일한 숫자 원천**입니다. 비어 있으면 리포트에 "데이터 없음"으로 나옵니다.

표 항목: 채널별 게시 수 / 조회·저장·클릭(Pinterest·TikTok·Reels·Shorts 분석) / Etsy 방문·주문·매출 / Shopify 주문·매출 / 문의 수·답장 수 /
오늘 배운 것 1줄 / 내일 AI에게 바라는 것 1줄(다음 밤 `night-pins`·`night-videos`가 읽음).

체크박스: 표 아래 `☐ 게시 창 1 / ☐ 게시 창 2 / ☐ 고객 확인 3회 / ☐ 일지 작성` — 끝낸 칸을 `☑`로.
